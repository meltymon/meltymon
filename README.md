## Infrastruktur & Engineering

### Proxmox HA / Ceph Cluster

Aufbau und Betrieb einer mehrknotigen, GPU-beschleunigten Infrastruktur auf Basis von Proxmox und Ceph.

- Acht Lenovo ThinkStation P900 Nodes
- Dual Intel Xeon E5-2699 v3 pro Node
- 1 TB DDR4 ECC RAM pro Node
- NVIDIA H100 80 GB und RTX A5000 24 GB pro Node
- NVMe- und Massenspeicherinfrastruktur
- 10-GbE-Netzwerkanbindung
- Umfassende Flüssigkeitskühlung
- Inkrementelle Backups in ein Cloud-Rechenzentrum und einen räumlich getrennten zweiten Cluster

### Legacy Hardware & Linux Performance Engineering

Performance-Optimierung und Verlängerung der Nutzungsdauer älterer Hardware unter Linux.

Praxisbeispiel: Lenovo ThinkStation P700 mit Dual-Xeon-Architektur und Intel Arc A750.

Schwerpunkte sind NUMA-aware CPU- und Speicherzuordnung, Prozessbindung, Vulkan, DXVK, VKD3D-Proton und individuelle Steam-Konfigurationen.

### Historische Erfahrung: MMORPG Server Infrastructure

Vor über zehn Jahren war ich am Betrieb einer größeren privaten World-of-Warcraft-Serverinfrastruktur beteiligt.

- 12 eigenständige Realms auf jeweils eigenen Dedicated Root Servern
- Intel Xeon Haswell mit jeweils 64 GB RAM
- Separate Server für Accountverwaltung und Homepage
- Separate Server für FTP, Mail und Datenbank
- Separate Server für Proxy-, Backup- und Datensicherungsdienste
- MaNGOS, Ascend/Antrix und SQL/MariaDB
- Mehr als 100.000 Spieler innerhalb eines Halbjahres nach damaliger Projektangabe

Das Projekt umfasste den Betrieb einer verteilten MMORPG-Infrastruktur mit klar getrennten Serverrollen und eigenständigen Diensten.

- Eight Lenovo ThinkStation P900 nodes

- More than 100,000 players within a six-month period, according to historical project figures

The project involved operating distributed MMORPG infrastructure with clearly separated server roles and independent services.
